# Changelog

## [Unreleased]

## [2.0.0] - 2026-11-15

Foundry v14 version. Same features as 1.0.0, updated for Foundry v14, dnd5e 6 and pf2e 8.
pf1e isn't on Foundry v14 yet, so it's only supported in the v13 version for now.

- Fate Reroll buttons and banners sit next to the chat message instead of inside it, since dnd5e 6
  redraws the message after it's shown.
- pf2e's hero point reroll is hidden again (Foundry v14 changed how chat menu entries are named).

## [1.0.0] - 2026-11-15

Same as 0.1.0, now on its own Foundry v13 release channel. If you installed 0.1.0, reinstall from the v13 manifest URL in the README so you keep getting v13 updates.

## [0.1.0] - 2026-11-15

First release.

- Fate Dice pool with a HUD, GM panel and per-character log
- Fate Reroll for dnd5e, pf2e and pf1e
- Shop with JSON import/export
- Nominations, approved by the GM or by player vote
